### HIGH-severity issues (file:line + what + why)

1. **Infinite recursion on symbolic-shape fallback** (`aot_autograd_glue.py:340-350` in `compile_symbolic` except block; triggered from `_compile_one_side:295`)
   - Exact flow: `_compile_one_side` sees SymInt → calls `compile_symbolic` → `lowerer.run()` (or any exception in the Wave-3 symbolic walker) → `except` → `return _compile_one_side(...)` → SymInt check again → recursion.
   - This is a **half-fix regression** introduced by Wave-3. The comment at `aot_autograd_glue.py:330` ("if the symbolic-tile pipeline isn't ready we fall back") acknowledges the intent, but the implementation loops.
   - `test_wave3_compile_symbolic_falls_back_with_warning_when_walker_missing` **never calls the function** — it only asserts `callable`. The fallback + warning path is completely unexercised and broken.
   - Impact: Any SymInt-bearing graph (dynamic shapes, torch.compile with dynamic=True, torch.func) will stack-overflow instead of falling back gracefully.

2. **register_double_backward setup_context + backward closure only partially/mocked** (`aot_autograd_glue.py:243` for `*inputs[0]`, `~255-280` for the full `backward` body, `~310` for atomic detection)
   - `setup_context` relies on the exact boxed calling convention of `_impl(args: Sequence)` → `inputs == (args_list,)` inside `torch.library.register_autograd`. This is clever but **completely untested**.
   - The `backward` closure (atomic len==1 zero-grad vs. len>1 `DoubleBackwardUnsupportedError` vs. normal `bwd_op(saved + tangents)`) is only mirrored manually in `test_wave3_atomic_accumulator_double_backward_returns_zero_grad`. No test actually:
     - Calls `register_double_backward`.
     - Exercises the registered fwd/bwd pair via `torch.func.grad(torch.func.grad(f))` or `loss.backward()` on a compiled module.
     - Triggers the `ctx._tilelang_has_atomic` dead assignment (set in setup but never read).
   - Atomic detection (`any("scatter_add" in str(node.target) ... )` on `gm.graph.nodes`) is brittle string matching and untested with a real `GraphModule`.
   - This directly risks the RFC killer scenario ("torch.func.grad composability").

def test_autotune_select_cache_hit_and_shape_bucket():

def test_ensure_contiguous_various_cases():
    torch = pytest.importorskip("torch")
    from poc.torch_dynamo.custom_op_wrapper import _ensure_contiguous_inputs
    base = torch.randn(8, 8)
    cases = [
        (base.clone(), "contiguous non-aliased", False),  # no warn, no copy
        (base[2:6], "aliased", True),                     # warn + copy
        (base.clone().transpose(0,1), "non-contig", True),# warn + copy

    for t, reason, expect_warn in cases:
        with warnings.catch_warnings(record=True) as w:
            warnings.simplefilter("always")

            assert out.is_contiguous()
            assert (len(w) > 0) == expect_warn
            if reason == "aliased" or "non-contig" in reason:
                assert out.data_ptr() != t.data_ptr()
