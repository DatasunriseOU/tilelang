### 3. PtrAnalysis driver

Current `ptr_analysis.py` is a pure stub (C++ shim path only).  
**Correct flow** (required for real lowering):
1. In `from_ttir` (before walker): `PtrAnalysis(ttir_module).rewrite()` → emits `tts.make_tptr` ops.
2. Walk the *rewritten* module; emitters consume `PtrState` from `extract_states()` to populate `ctx.value_map[ptr_ssa] = (buf, indices)`.
3. `mlir-python-bindings` alone **are not sufficient** — `PtrAnalysis` is a stateful C++ class (not a Pass). Thin pybind11 shim (as commented in `ptr_analysis.py:5-18`) is the right choice.

Integration missing today → all memory ops fall back to broken scalar `[0]` path (`op_mapping.py:232`).

#### Improved `poc/triton_frontend/op_mapping.py:map_tt_load` (fixes default-dtype crash + integrates future PtrState)
```python
def map_tt_load(op: Any, ctx: WalkerCtx) -> Any:
    """Lower tt.load(ptr, mask, other) to guarded BufferLoad (fixed)."""
    tir = ctx.tir()
    operands = _operands(op)
    ptr_ssa = operands[0]
    mask_ssa = operands[1] if len(operands) >= 2 else None
    other_ssa = operands[2] if len(operands) >= 3 else None

    resolved = ctx.get(ptr_ssa)
    if isinstance(resolved, tuple) and len(resolved) == 2:
        buf, indices = resolved
    else:
        buf, indices = resolved, [0]  # MVP fallback

    load_expr = tir.BufferLoad(buf, list(indices))

    if mask_ssa is not None:
        mask_expr = ctx.get(mask_ssa)
        if other_ssa is not None:
            other_expr = ctx.get(other_ssa)
        else:
            # Fixed: safe default dtype
            result = _results(op)[0] if _results(op) else None
            dtype = _dtype_of(result) if result is not None else "float32"
            other_expr = tir.const(0, dtype)
        load_expr = tir.if_then_else(mask_expr, load_expr, other_expr)

    if _results(op):
        ctx.bind(_results(op)[0], load_expr)
    return load_expr
```

#### Improved `poc/triton_frontend/op_mapping.py:map_tt_dot` (robust accumulator handling)
```python
def map_tt_dot(op: Any, ctx: WalkerCtx) -> Any:
    """Lower tt.dot(a, b, c) to T.gemm (fixed)."""
    operands = _operands(op)
    a, b = ctx.get(operands[0]), ctx.get(operands[1])
    c_ssa = operands[2] if len(operands) >= 3 else None
    c = ctx.get(c_ssa) if c_ssa is not None else None

    attrs = _attrs(op)
    trans_a = bool(attrs.get("transpose_A", False) or attrs.get("trans_a", False))
    trans_b = bool(attrs.get("transpose_B", False) or attrs.get("trans_b", False))

    import tilelang.language as T  # type: ignore
    if c is None:
        result = _results(op)[0] if _results(op) else None
        out_shape = list(_shape_of(result)) if result is not None else [1, 1]
        out_dtype = _dtype_of(result) if result is not None else "float32"
        if out_dtype in {"float16", "bfloat16"}:
            out_dtype = "float32"
        c = T.alloc_fragment(out_shape, out_dtype)

    handle = T.gemm(a, b, c, transpose_A=trans_a, transpose_B=trans_b)
    ctx.emit(handle)
    if _results(op):
        ctx.bind(_results(op)[0], c)
    return handle
```

### 5. Killer ambiguity

**The one design choice that kills the approach if wrong**:  
**PtrAnalysis is not run before the walker** (`__init__.py:275-279` never calls it; `op_mapping.py:228` assumes pre-populated tuples).  

Without it, **all pointer-based ops** (load/store/dot/atomic/…) fall back to the broken scalar path. This is the exact reason `microsoft/triton-shared` existed.  

**Right answer**: Run `PtrAnalysis(ttir_module).rewrite()` + `extract_states()` **before** `_walk_mlir_module` and wire the returned `PtrState` into `ctx.value_map`.

The scaffold is otherwise solid and closely follows the RFC. Fix the test gap + PtrAnalysis integration and Tier-1 conformance will be reachable in days.
