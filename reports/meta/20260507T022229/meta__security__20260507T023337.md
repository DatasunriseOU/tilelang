## Finding 1
- **Severity**: medium  
- **File**: `CMakeLists.txt:269`  
- **Issue**: Build option `TILELANG_BUILD_TESTS` defaults to `ON` and gates registration of test-only FFI helpers like `tl.z3.bv_can_prove` and `tl.z3.bv_scoped_round_trip`. If a release wheel is built without explicitly passing `-DTILELANG_BUILD_TESTS=OFF`, these diagnostic symbols ship to users. Exposing test harnesses that wrap the Z3 prover allows untrusted Python callers to trigger arbitrary SMT queries, potentially causing high CPU/memory via pathological formulas. This is a classic debug-interface-in-production issue.
- **Fix**: Flip the default to `OFF` and only enable in CI/test builds. Minimal patch:
  ```diff
  -option(TILELANG_BUILD_TESTS "Build test-only FFI helpers (e.g. Z3 bv probes)" ON)
  +option(TILELANG_BUILD_TESTS "Build test-only FFI helpers (e.g. Z3 bv probes)" OFF)
  ```
  Then explicitly set `-DTILELANG_BUILD_TESTS=ON` in test workflows.
