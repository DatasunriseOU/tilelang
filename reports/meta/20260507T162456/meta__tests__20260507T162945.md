**284a907e — `_detect_storage_overlap` short-circuit**
`dsa_splitk_indexer_loss.py:118`
```python
def _detect_storage_overlap(buffers):
    if len(buffers) <= 1: return False
    # short-circuit: check if max_start >= min_end
    starts = [b.byte_offset for b in buffers]
    ends = [b.byte_offset + b.nbytes for b in buffers]
    if max(starts) >= min(ends):
        return False # disjoint case O(n)
    #... O(n^2) pairwise check for overlap case
```

**Finding: Correct complexity fix, but missing test for `nbytes=0`**
